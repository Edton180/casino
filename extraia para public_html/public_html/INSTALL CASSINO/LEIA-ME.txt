COMO INSTALAR
=============

A instalação agora é automática. Não é mais preciso importar SQL nem editar o .env.

1. Envie os arquivos para a hospedagem (veja o guia completo em INSTALACAO.md na raiz do repositório).
2. Crie um banco MySQL vazio e um usuário com todos os privilégios.
3. Acesse  https://SEU-DOMINIO/install/  e siga o assistente.

O assistente cria o banco (database/install/base.sql), o arquivo .env e o seu
usuário administrador. Depois acesse  https://SEU-DOMINIO/admin

Não existe mais usuário/senha padrão (o antigo admin@admin.com / 123456 foi removido).

Pasta "banco de dados playfiver.zip": lista de jogos do provedor PlayFiver, usada
apenas por quem contratar esse provedor (importação manual opcional).
